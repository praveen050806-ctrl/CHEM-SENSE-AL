# CHEM-SENSE AI — Project Website

A single-file, zero-install website summarising the CHEM-SENSE AI concept
(dynamic freshness intelligence for smart food packaging), including a
working Fresh / Warning / Spoiled indicator demo.

## How to run

No build step and no server required.

1. Unzip this package.
2. Open `web/index.html` directly in Chrome, Edge, or Firefox.
3. Use the **Fresh / Warning / Spoiled** buttons in the hero demo to see the
   score, verdict, and pipeline indicator update.

## What's inside

- `web/index.html` — the entire site (HTML, CSS, and JS in one file, no
  external dependencies or network calls).

## Sections

1. Hero + live indicator demo
2. The problem (fixed dates vs. actual condition)
3. The solution (five-layer pipeline)
4. Applications (dairy, seafood/meat, produce, logistics, retail)
5. Real-world feasibility
6. Anticipated judge questions
7. Scientific integrity note & future scope
8. Closing pitch
